01 / THE IDEA

Work starts with an email.

No new chat to check. TagMails connects an address to an agent running on your Mac, then sends the result back to the conversation you started.

01

Set up your agent

Choose Codex or Claude Code and pair a selected workspace. Your local model sign-in stays on your computer.

02

Send the task

Email the agent from your verified Gmail address. Ask for a model by name when you want one; otherwise use your default.

03

Reply to continue

Get a concise result, checks, and links to artifacts. Reply in the same thread to refine the work or answer a question. In Gmail, react with an emoji when the message supports it.

02 / THE WORK

Bring it into the thread.

The best tasks already live in your inbox: a bug report, a messy decision, a question before a call. Forward context, ask for a result, and come back to the answer.

04 / PRICING
Pay for the mailbox. Choose how the model runs.
