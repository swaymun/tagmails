## Stop conditions

Stop and preserve the job and provider IDs if a reply names the wrong recipient, a duplicate send appears, two Macs claim one thread, a run claims an unverified file change, a participant gains access without an owner grant, a signed event cannot be matched to its provider record, or a reply is blocked because its source is missing. Do not retry an uncertain send until Resend's sent record and API logs settle whether it was accepted.
